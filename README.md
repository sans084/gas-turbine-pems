# Gas Turbine Emissions Monitoring (PEMS)
Machine learning models to predict NOx and CO emissions of a gas turbine
from process sensor data, with a monitoring dashboard.

## Dataset
UCI Gas Turbine CO and NOx Emission Data Set (Kaya, Tufekci & Uzun, 2019).
Hourly data from one gas turbine in north-western Turkey, 2011-2015, 36,733 rows,
9 sensor inputs, targets CO and NOx (mg/m3).
Source: https://doi.org/10.24432/C5WC95
Files used: yearly CSVs obtained from a public GitHub copy of the dataset.
